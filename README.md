# 📡 LiveTrack Rally - Stable Release

![Version](https://img.shields.io/badge/version-1.0.0--stable-green)

**LiveTrack Rally** est une application web de suivi GPS en temps réel. Cette version est la version stable officielle validée sur GitHub Pages.

---

## ✨ Fonctionnalités
- **Suivi GPS** : Synchronisation avec Telegram pour le live-tracking.
- **Gestion GPX** : Importation et visualisation multicouche.
- **Alertes** : Détection d'immobilisation et de hors-trace.
- **PWA** : Compatible mobile via GitHub Pages.
