Bienvenue sur LiveTrack V2

Configuration de votre assistant de course

Mode Automatique 100% Cloud
LiveTrack utilise un Bot Telegram pour communiquer en temps réel avec les pilotes.
Étape 1 : Créer votre Bot
  1. Ouvrez Telegram et cherchez @BotFather.
  2. Envoyez la commande /newbot.
  3. Suivez les instructions pour choisir un nom.
  4. @BotFather vous donnera un Token HTTP API (ex: 1234:ABC...).
Étape 2 : Validation du Token

Copiez le Token fourni par @BotFather et testez la connexion.

Étape 3 : Invitation Pilotes

Votre assistant est configuré. Les pilotes peuvent maintenant s'y connecter.

Dans l'application (Menu Paramètres ⚙️ > Gestion des Pilotes 👥), un QR Code est disponible pour que vos pilotes rejoignent votre bot.
