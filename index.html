🎮 Simulation
Démarrer en mode simulation
Le mode simulation génère 5 pilotes fictifs qui suivent (et dévient de) la trace. Idéal pour tester les alertes sans participants réels.
🔌 Connexion serveur (live)
Connectez un serveur WebSocket qui reçoit les positions Telegram.
Chaque message doit avoir le format :
{ "type": "position", "participant": { "id", "name", "lat", "lng", "color", "avatar" } }
✈️ Bot Telegram
1. Créez un bot via @BotFather sur Telegram
2. Demandez aux pilotes de partager leur Live Location dans le chat du bot
3. Démarrez le serveur Node.js fourni avec TELEGRAM_TOKEN=...
4. L'URL WebSocket à entrer ci-dessus est ws://votre-serveur:3000
